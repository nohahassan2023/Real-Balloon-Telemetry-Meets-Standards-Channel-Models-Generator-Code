# HAPS Channel Simulation Code: Real Flight Data + Standards-Based Propagation

## What this is
This is the code for the paper: Real Balloon Telemetry Meets Standards Channel Models: A Link Dataset for High-Altitude Platform Station Communication.
Code for generating and analyzing labeled HAPS (High Altitude Platform Station)
communication link scenarios, as used in "Real Balloon Telemetry Meets Standards Channel Models: A Link Dataset for High-Altitude Platform
Station Communications". The code combines **real measured flight data with established propagation standards**, so the
generated link scenarios are grounded in measurements rather than purely synthetic.
